# 解説と中核コード・担当クレートをつなぐ

2026-10-25。7つの解説すべてへ、中核となる代表コードと、そのソースを含むCargoパッケージへの入口を追加しました。

## 期待するメリット

1. 説明の言葉を、実際の入力・比較・戻り値へ対応させて確かめられます。たとえば、前のブロックを指すという説明を、ハッシュと番号を比べる検証で確認できます。
2. 担当クレートへ進むと、処理が属するまとまりと周辺のモジュールを調べられます。ローカル版はCargo設定・依存宣言も折りたたみで読めるため、別の部品との関係を追えます。
3. 説明へ戻る場所を保ち、一つの問いについて日本語とコードを往復できます。最後に読んだ別の解説ではなく、リンク元の解説をURLで指定します。

これは学習効果の期待であり、人間の理解率の向上を検証した結果ではありません。

## 表示の決め方

解説ごとに代表となるコードを一つ選び、何を確かめられるかを短く説明します。「中核のコードをこの場で読む」を開くと、適用範囲、固定版の実コード、用語・行・記号のヒントを表示します。原文と担当クレートへのリンクはその中に置きます。順に解説を読む主操作は保ち、コードを開くだけで「読んだ」や理解済みの認定を付けません。

ブロックチェーンという一般概念を、Rethの一関数がすべて実装するとは示しません。つながりの検査、履歴の採用、確定は区別します。Rethの役割を読む箇所も、合意側クライアントの選択・確定処理そのものへ結び付けたとは扱いません。

## 根拠と遷移

ui/lesson-code-links.jsonでは解説・コード文脈・選定理由・適用範囲を定義します。ビルド時に、固定Gitのソースを含む最寄りのCargo.tomlから実際のパッケージ名とハッシュを取得します。ディレクトリ名や責務でまとめた構成グループを、そのまま実際のクレート名とはしません。

ローカル版では既存の読解・クレート画面へ進み、URLのlessonにより元の解説へ戻れます。内部のモジュール・関数へ進んでも同じ文脈を引き継ぎます。静的版は同じページで抜粋を読め、原文・クレートの固定コミットをGitHubの別タブで開きます。
